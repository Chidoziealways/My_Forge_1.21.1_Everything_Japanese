# Contributing to Everything Japanese

Thanks for wanting to contribute! Whether it’s bug fixes, new features, or optimizations, we appreciate your help. Follow these simple rules to keep contributions smooth:

## How to Contribute
1. Fork the repository.
2. Create a new branch for your work
3. Make your changes, following the existing code style.
4. Commit your changes
5. Push to your branch
6. Submit a pull request here.

## Guidelines
- Keep the MIT License intact—don’t remove my credit.
- Respect the Minecraft version compatibility.
- Make sure new features are thoroughly tested before submitting.
