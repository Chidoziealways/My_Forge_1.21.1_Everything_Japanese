# Everything Japanese

Everything Japanese is a Minecraft mod set in ancient Japan, packed with quests, stages, and custom systems that bring the world alive. From castles to mysterious bosses, everything is crafted to give you a rich, immersive experience.

## Features
- Custom Quests with rewards
- Custem Item, Jutsu Scrolls
- Talisman
- Chakra
- Money Update & other quality-of-life improvements
- Designed for Minecraft 1.21.8 (some versions may be unsupported)

## Installation
1. Ensure you have Minecraft 1.21.8 installed.
2. Place the mod `.jar` in your `mods/` folder.
3. Launch Minecraft and enjoy the experience.

## Requirements
- NeoForge 1.21.8+
- Java 21+
